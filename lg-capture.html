LEAGUEGAMING PUBLIC LOG BRIDGE

ONE CLICK.
NO COPY/PASTE.

This bookmark runs only when you click it on LeagueGaming. You can run it directly from a normal LG game page. It uses that game ID to request the matching Public Log inside your already-open LG browser session, then forwards only the public log text to Wildman Tournament Control. It does not send your LG cookies, password or session tokens to Wildman.
